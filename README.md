# Hospital Medical Records Web App (Frontend)

Modern Vue 3 web interface for managing hospital patient records, featuring dynamic department forms and robust unit testing.

## 🚀 Features

- **Patient Records Modal:** Interactive modal for creating and updating patient files across various departments (Cardiology, Emergency, Oncology, General Medicine).
- **Dynamic Form Handling:** Real-time form updates tailored to medical department specifications.
- **API Integration:** Axios client equipped with request/response interceptors for smooth authentication handling.
- **Unit Testing Suite:** Complete Jest unit tests with over 70% code coverage.

## 🛠️ Tech Stack

- **Framework:** Vue 3 
- **Language:** TypeScript
- **Testing:** Jest, `@vue/test-utils`
- **HTTP Client:** Axios
